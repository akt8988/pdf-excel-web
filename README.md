# PDF/画像 表抽出・Excel変換ツール（pdf-excel-web）

PDFや表の画像から表構造を検出し、Excel（.xlsx）形式へ変換する、完全クライアントサイドのWebアプリです。ファイルはサーバーに送信されず、全ての処理がブラウザ内で完結します。

`index.html` をブラウザで開くだけで使えます（ライブラリをCDNから読み込むため、インターネット接続が必要です）。

## 特徴

- 対応形式: PDF（.pdf）、画像（.png / .jpg / .jpeg / .webp）
- 読み込み時に罫線を自動検出して、縦・横のガイド線を初期配置
  - 縦線・横線で別々の検出閾値スライダー（縦線は表示50%＝実効40%の目盛り、横線は表示＝実効値）
  - ページ端から6px以内の線は、ノイズ除けのため検出対象外
- ルーラー操作でガイド線を調整（UI主導）
  - 上部ルーラーのクリックで縦線（赤破線）、左側ルーラーで横線（青破線）を追加
  - 線はドラッグで移動、ルーラー上のマークをクリックで1本だけ削除、「すべての線を削除」で一括クリア
  - 追加・移動・削除・一括削除は「戻る」ボタンと Ctrl+Z（Macは Cmd+Z）で取り消し可能（やり直しは Ctrl+Shift+Z / Ctrl+Y）
- テキスト抽出はハイブリッド方式
  - PDFにテキスト層がある場合は、セルの座標からテキストを直接取得
  - 画像やスキャンPDFは、セル範囲だけを Tesseract.js でOCR
- 右側の抽出プレビューはガイド線の変更に連動して更新され、セルをその場で直接編集可能
- Excel書き出し
  - ツールバーとプレビュー下部の「Excelでダウンロード」ボタンから書き出し
  - SheetJS でカラム幅を自動調整した .xlsx をダウンロード
- 複数ページPDF対応
  - ページ切替とズーム（幅フィット含む）
  - 「全ページで共通のガイド線を使う」モード（全ページを走査し、過半数のページに現れる位置を共通線として採用）
  - 「このページのガイド線を全ページに適用」ボタン
  - 全ページの行を連結した統合プレビューと、見出し重複行を除外して1シートに書き出す出力（ファイル名に `_all`、ページ単位出力では `_p{ページ番号}` が付きます）

## 使い方

1. `index.html` をブラウザで開く
2. PDFまたは画像をドロップ（または「ファイルを選択」）
3. 自動配置されたガイド線を、ルーラーで追加・移動・削除して表に合わせる。必要に応じて縦・横の閾値スライダーを調整する
4. 右側プレビューで内容を確認し、間違いはセルをクリックして直接直す
5. 「Excelでダウンロード」で .xlsx を保存する

## 技術

- HTML5 / CSS3 / Vanilla JS（単一HTMLファイル）
- pdf.js（PDF描画・テキスト層取得）
- Tesseract.js（ブラウザ内OCR）
- SheetJS (xlsx)（Excel生成）
- FontAwesome v6（アイコン）

いずれもCDNから読み込みます。
